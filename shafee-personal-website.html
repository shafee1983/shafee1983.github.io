MGMT 431 · Python · Classroom prototype

Workplace Automation: Overdue Tasks Report

In my Future of Work course, I worked with a Python notebook that reads fictional task records, identifies open tasks with dates before September 17, 2026, and presents them in a readable report.

Saved sample result: Five overdue open tasks were identified in the notebook output. This is a classroom exercise, not a live workplace tool.

Explore the workflow and limitations

Input: A small CSV dataset containing task names, owners, due dates, and status.

Rule: Select tasks marked open with a due date earlier than the reference date.

Output: A list and formatted HTML report showing the overdue tasks.

Limitation: The notebook includes mixed exercise inputs, including an expense dataset and a separate email-language stress-test sample. The saved overdue-task result does not demonstrate that those other cases were validated with the same rule.

Learning: A useful automation needs a clear input, a specific rule, a readable report, and testing against realistic edge cases.

MGMT 431 · AI literacy

Performance Review Language Analysis

In class, I explored a fictional performance appraisal for a marketing coordinator and how AI-supported drafting and language review can help prepare a more specific, behavior-based manager conversation.

What this exercise explores

The workshop introduces a multi-agent workflow: organize review notes, draft an appraisal, check wording for possible bias, and prepare a manager conversation. An NLP scanner can look for word choices, trait versus action language, and specificity.

Important limit: The uploaded materials explain the workflow but do not include my complete scanner outputs here. No measured bias finding or validated accuracy claim is presented.
